1. Synthèse du Cours & Fondements Théoriques des ACL

Une Access Control List (ACL) est une liste ordonnée de règles (ACE - Access Control Entry) appliquée sur un équipement réseau (routeur, switch L3) permettant d'autoriser (permit) ou d'interdire (deny) le transit de paquets en fonction d'adresses IP, de protocoles et de ports TCP/UDP.

Algorithme de lecture :
  1. Séquentiel : Évaluation de haut en bas (du plus spécifique au plus général).
  2. Première correspondance : Dès qu'une règle correspond, l'action est exécutée et l'analyse s'arrête immédiatement.
  3. Deny implicite : Tout paquet ne correspondant à aucune règle explicite est silencieusement rejeté (deny ip any any).
  4. Stateless (sans état) : Chaque paquet est analysé isolément, sans mémoire de la session retour (utilisation de established pour TCP).

Calcul du Wildcard Mask

Le wildcard mask est le masque inversé : un bit à 0 indique une correspondance stricte, un bit à 1 est ignoré. Formule : Wildcard = 255.255.255.255 - Masque de sous-réseau.

  • /24 (255.255.255.0) → 0.0.0.255
  • /30 (255.255.255.252) → 0.0.0.3
  • Hôte unique (/32) → host IP ou 0.0.0.0
  • Tout le trafic (/0) → any (0.0.0.0 255.255.255.255)

2. Architecture de la Maquette (Entreprise SISR2)

Topologie du TP02 : Siège ←→ Liaison Série 1.1.1.0/30 ←→ Agence

[LAN SIÈGE 192.168.1.0/24] (Web .251, DNS .252, DHCP .250, PC1 .111, PC2 .112)
                                  | Gi0/0
                        [Routeur R1] (192.168.1.1 / 1.1.1.2)
                                  | Se0/0/0 (Liaison WAN 1.1.1.0/30 DCE)
                        [Routeur R2] (1.1.1.1 / 172.16.1.1)
                                  | Gi0/0
[LAN AGENCE 172.16.1.0/24] (Serveur-Agence .100 HTTP/FTP, PC3 .10)

Politique de Sécurité à implémenter :

  • R1 : Les postes du LAN Siège ne doivent pas pouvoir envoyer de ping vers le réseau d'interconnexion 1.1.1.0/30.
  • R2 : PC2 (192.168.1.112) ne doit avoir aucun accès au réseau de l'agence.
  • R3 : Depuis le LAN Siège, le Serveur-Agence (172.16.1.100) n'est accessible qu'en HTTP (TCP 80). Le reste de l'agence (PC3) reste joignable.
  • R4 : Depuis l'agence, seuls sont autorisés vers le siège : le serveur Web (HTTP) et le serveur DNS (DNS UDP 53). Les réponses aux connexions initiées depuis le siège doivent passer.

3. Réponses aux Questions & Configurations Réalisées

Partie B – Analyse & Wildcard Masks (B1 à B5)
  • 192.168.1.0 /24 : Wildcard = 0.0.0.255
  • 1.1.1.0 /30 : Wildcard = 0.0.0.3 (255.255.255.255 - 255.255.255.252)
  • 10.0.0.0 /8 : Wildcard = 0.255.255.255
  • Ordre de lecture (B2.1) : Si permit ip any any est placé avant le deny ICMP, le ping n'est pas bloqué car la première règle autorise tout le trafic et stoppe l'évaluation. Il faut placer la règle spécifique deny icmp au-dessus.
  • Deny implicite (B2.2) : Si l'on ne laisse que deny icmp, tout le trafic HTTP est bloqué à cause du deny implicite final.
  • Sens in / out (B3.1) : Aller (PC1→PC3) : R1 Gi0/0 (in), R1 Se0/0/0 (out), R2 Se0/0/0 (in), R2 Gi0/0 (out). Retour (PC3→PC1) : R2 Gi0/0 (in), R2 Se0/0/0 (out), R1 Se0/0/0 (in), R1 Gi0/0 (out).
Partie C – Règle R2 : ACL Standard sur R2 (Isolation de PC2)

Une ACL standard ne filtre que la source : pour ne pas bloquer PC2 vers son propre LAN ou d'autres destinations, on la place au plus près de la destination : sur le routeur R2, interface Gi0/0, sens out.

R2(config)# access-list 10 deny host 192.168.1.112
R2(config)# access-list 10 permit any
R2(config)# interface gigabitEthernet 0/0
R2(config-if)# ip access-group 10 out

Limite constatée (C6) : Si PC2 change d'adresse IP (ex: 192.168.1.113), le filtrage devient inopérant. D'où la nécessité de combiner ACL avec DHCP Snooping, 802.1X ou filtrage par VLAN.

Partie D & E – Règles R1 & R3 : ACL Étendue Nommée sur R1 (FILTRE_LAN)

Pour R1 et R3, nous déployons une ACL étendue nommée FILTRE_LAN sur R1 (Gi0/0 in) regroupant l'interdiction du ping vers le WAN, l'autorisation stricte HTTP vers le Serveur-Agence, et l'interdiction du reste vers ce serveur :

R1(config)# ip access-list extended FILTRE_LAN
R1(config-ext-nacl)# 10 deny icmp 192.168.1.0 0.0.0.255 1.1.1.0 0.0.0.3
R1(config-ext-nacl)# 20 permit tcp 192.168.1.0 0.0.0.255 host 172.16.1.100 eq 80
R1(config-ext-nacl)# 30 deny ip 192.168.1.0 0.0.0.255 host 172.16.1.100
R1(config-ext-nacl)# 40 permit ip any any
R1(config)# interface gigabitEthernet 0/0
R1(config-if)# ip access-group FILTRE_LAN in
Partie F – Règle R4 : Filtrage Agence → Siège (Liste Blanche & Established)

Conception d'une ACL en liste blanche AGENCE_IN appliquée sur R2 Gi0/0 in. On autorise le HTTP vers le Web, le DNS vers le serveur DNS, les réponses TCP initiées depuis le siège grâce à l'option established (ACK/RST), et les réponses ICMP (echo-reply) :

R2(config)# ip access-list extended AGENCE_IN
R2(config-ext-nacl)# permit tcp 172.16.1.0 0.0.0.255 host 192.168.1.251 eq 80
R2(config-ext-nacl)# permit udp 172.16.1.0 0.0.0.255 host 192.168.1.252 eq 53
R2(config-ext-nacl)# permit tcp 172.16.1.0 0.0.0.255 192.168.1.0 0.0.0.255 established
R2(config-ext-nacl)# permit icmp 172.16.1.0 0.0.0.255 192.168.1.0 0.0.0.255 echo-reply
R2(config-ext-nacl)# deny ip 172.16.1.0 0.0.0.255 192.168.1.0 0.0.0.255
R2(config-ext-nacl)# permit ip any any
R2(config)# interface gigabitEthernet 0/0
R2(config-if)# ip access-group AGENCE_IN in

4. Bilan Professionnel & Cybersécurité

Question de BilanAnalyse Technique & Recommandation
Limites du filtrage stateless (H1)Les ACL ne conservent pas l'état des sessions : elles exigent des ouvertures manuelles ou l'usage de established (facilement contournable par spoofing de flags). Solution : Pare-feu d'état (Stateful Firewall / Cisco ASA / pfSense).
Fragilité du filtrage par IP (H2)Une adresse IP peut changer via DHCP ou être usurpée. Solutions : filtrage basé sur l'authentification 802.1X, segmentation par VLANs de rôle, et inspection dynamique ARP (DAI) / DHCP Snooping.
Politique Liste Blanche vs Liste Noire (H3)La liste noire (terminant par permit ip any any) autorise tout par défaut sauf les menaces connues (faible sécurité). La liste blanche (rejetant tout par défaut) respecte le principe de moindre privilège recommandé par l'ANSSI.
